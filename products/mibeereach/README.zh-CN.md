## 它做什么

MiBeeReach 是一个用 Rust 从零构建的远程运维平台。远程桌面、远程终端、SSH、内网隧道共享同一连接层与同一设备身份——一切流量都在你的局域网之内，**全程不经第三方**。

| 商用远程桌面服务的痛点 | MiBeeReach 的回答 |
|---|---|
| 限速 / 限额 | 自有基础设施——不限速、不限额 |
| 广告打扰 | 纯工具，无广告 |
| 隐私黑盒（流量过厂商服务器） | 自部署、全程加密、流量不出你的网络 |
| 画质 / 延迟不可控 | 全链路自研，皆可调 |

## 能力版图

| 能力 | 说明 | 平台 |
|---|---|---|
| **远程桌面** | 视频、键鼠、剪贴板（文本 / 图片 / 文件）、音频、文件互传、多显示器、只读模式 | 被控端：Windows · Linux — 主控端：Windows · macOS |
| **远程终端** | 局域网内的远程 shell | Windows · Linux |
| **远程 SSH** | 内置 SSH server，任何标准 `ssh` 客户端都能直连 | Windows · Linux |
| **内网穿透隧道** | 安全地对外暴露内网 TCP 服务 | Windows · Linux |
| **管理控制台** | 桌面应用：快速连接、局域网设备发现、工作区、内嵌终端、SSH 页签、会话监控 | Windows · macOS |

为真实网络而做：弱网自适应画质、无人观看时几乎零 CPU、可选硬件视频编码。

## 安全

- **全程加密**：连接一律加密，路径上没有第三方。
- **必须配对**：无凭据的连接直接拒绝，已配对设备免确认连接。
- **会话级权限**：控制、剪贴板、文件分别授权，另有只读模式。

更多平台支持在规划中。使用文档随每个 Release 一同发布。
